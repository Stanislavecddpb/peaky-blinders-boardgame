# Brass: Birmingham — веб-версия

Браузерная версия настольной игры **Brass: Birmingham** (2–4 игрока) для игры с друзьями:
по ссылке через интернет или за одним компьютером. Полностью автоматизированные официальные правила,
русский интерфейс, оригинальные изображения поля, карт и плиток.

## Запуск у себя

```
npm install
npm run play      # http://localhost:3001
```

Разработка: `npm run dev:server` и `npm run dev:client` (http://localhost:5173).
Тесты движка: `npm test`.

## Игра по сети

Задеплойте на Render (файл `render.yaml`: Blueprint → репозиторий) или откройте локальный сервер наружу:
`ngrok http 3001`. На главной «Создать игру», скопируйте ссылку и отправьте друзьям; каждый занимает место,
выбирает цвет, хост начинает партию.

Партии сохраняются на диск (папка `data/matches` или переменная `MATCHES_DIR`) и переживают перезапуск сервера;
закрытая вкладка возвращает игрока на его место по той же ссылке. На бесплатном плане Render диск временный:
после засыпания сервера (~15 минут простоя) партии пропадают.

Когда нужен ваш ход, у вкладки появляется «● Ваш ход» (и короткий звук, если окно не в фокусе).
То, что сделал предыдущий игрок, несколько секунд подсвечивается на поле голубым.

## Игра за одним компьютером

«Игра за одним компьютером» на главной. Перед каждым ходом экран закрывает карты, пока не подойдёт
следующий игрок. Партия сохраняется в браузере: после перезагрузки страницы её можно продолжить.

## Как ходить

Справа — панель хода: выберите действие (Строить, Сеть, Развивать, Продать, Заём, Разведка, Пропуск),
затем карту на руке — подходящие подсвечены. Потом цель на поле: подсвечиваются слоты, связи или ваши плитки.
То же самое можно выбрать списком в панели. Если источник угля, железа или пива можно выбрать
(несколько одинаково близких шахт, разные заводы или пивоварни, бочка торговца с бонусом), появится
селектор; иначе игра берёт ресурсы по правилам сама. Перед подтверждением видно, сколько это стоит
и что произойдёт. «↶ Отменить действие» работает до «Завершить ход»; добор карт уже не отменить.

«Мой планшет» внизу — следующие плитки каждой отрасли со стоимостью, ПО, доходом и значками связей;
у соперников — ссылка «планшет» в списке игроков. Колесо мыши — зум поля, перетаскивание — прокрутка,
двойной клик — всё поле.

## Что автоматизировано

Все правила базовой игры: подготовка по числу игроков (колода 40/54/64, торговцы), две эпохи,
шесть действий, сеть и связность, приоритет слотов, перестройка, рынки угля и железа (покупка и продажа),
ближайший уголь, пиво (своё, чужое по связи, торговцы и их бонусы, включая развитие у Глостера),
переворот плиток и доход, займы, порядок ходов по тратам, доход и долги в конце раунда, очки за связи
и плитки в конце эпохи, смена эпохи, финальный подсчёт с тай-брейками.

Упрощения: при отрицательном доходе без денег плитки для продажи выбираются автоматически
(сначала неперевёрнутые, с меньшими ПО); уголь для железных дорог берётся из ближайшей шахты автоматически.

## Ассеты

Изображения — официальные сканы из TTS-мода `ikegami/tts_brass` через репозиторий
`jiangshibiao/BrassBirmingham` (оттуда же разметка поля и таблицы данных), для личного некоммерческого
использования. Brass: Birmingham — торговая марка Roxley Games; проект с ними не связан.

Пересборка картинок (сырьё кладётся в `tools/assets/raw/`, в git не хранится):

```
python tools/assets/build_assets.py
```

Разметку поля можно проверить на странице `#/dev/board?turns=30&hl=1` (случайная позиция, подсветка всех слотов и связей).

## Проверки

- `npm test` — правила, случайные полные партии на 2/3/4 игроков, клиент boardgame.io (лобби, отмена, порядок ходов);
- `npx tsx scripts/net-play.ts http://localhost:3001 3` — полная сетевая партия ботами через сервер,
  переподключение, проверка, что чужие руки и колода не уходят по сети;
- `node scripts/hotseat-test.mjs http://localhost:3001 4` — партия за одним компьютером через интерфейс (puppeteer);
- `node scripts/shot.mjs <url> <файл.png>` — скриншот (размер окна: переменные `W`, `H`).

Если puppeteer не находит Chrome, укажите путь через `PUPPETEER_EXECUTABLE_PATH`.
