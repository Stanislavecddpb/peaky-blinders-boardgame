# Brass: Birmingham — веб-версия. Дизайн

Дата: 2026-10-19

## Цель

Браузерная версия настольной игры Brass: Birmingham (Гэвин Бирнбаум, Мэтт Таннер,
Дэвид Тёрнер; Roxley, 2–4 игрока) для игры с друзьями по ссылке и за одним компьютером.
Полностью автоматизированные официальные правила, русский интерфейс, оригинальные ассеты.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Стек | Как в `../ankh-morpork`: boardgame.io 0.50, React 18, Vite, Koa + socket.io, TypeScript, npm workspaces, vitest, puppeteer, деплой на Render |
| Переиспользование | Каркас (сервер, лобби, хотсит, сеть, стили страниц, скрипты проверки) переносим из ankh-morpork, игровую логику пишем заново |
| Ассеты | Картинки из `jiangshibiao/BrassBirmingham` (официальные сканы из TTS-мода `ikegami/tts_brass`, личное некоммерческое использование): поле 6144², листы карт, плитки, торговцы, монеты, жетоны |
| Данные | Таблицы плиток, карт, рынков, шкалы дохода, топология поля и координаты слотов/связей/треков берём из того же репозитория как данные, сверяем с правилами; код не копируем |
| Язык | Интерфейс и журнал на русском; на картах и поле английские надписи, в подсказках русские названия |
| Режимы | Онлайн по ссылке (лобби, переподключение, сохранение партий на диск) и хотсит. Ботов нет |
| Ввод | Мастер действия + клики по полю: игра подсвечивает допустимые карты, слоты, связи и источники ресурсов |
| Отмена | В пределах своего хода, до нажатия «Завершить ход» (добор карт неотменяем) |
| Правила | Только официальные, 2–4 игрока |
| Платформа | Десктоп, ширина от 1366 px |
| Git | Репозиторий в этой папке, remote `Stanislavecddpb/peaky-blinders-boardgame` |

## 1. Структура

```
packages/engine   — правила на boardgame.io: данные, состояние, действия, конец раунда/эпохи; vitest
packages/server   — Koa + socket.io + FlatFile (как в ankh-morpork), раздаёт собранный клиент
packages/client   — React + Vite: главная, комната, лобби, стол, хотсит
tools/assets      — Python (Pillow): сырые сканы → webp в packages/client/public
scripts           — puppeteer/node-проверки: сетевая партия, секретность, интерфейс, скриншоты
```

Сырые сканы (`tools/assets/raw/`) не коммитятся; готовые webp коммитятся.

## 2. Правила, которые реализует движок

### Компоненты и подготовка
- Поле: 20 городов + 2 фермерские пивоварни; 5 торговых точек (Shrewsbury 1 место, Gloucester,
  Oxford, Warrington, Nottingham — по 2). 39 связей, у каждой признаки «канал»/«железная дорога».
  Связь Kidderminster–Worcester соединяет также южную ферму.
- Плитки игрока (45 шт.): хлопок, мануфактура, гончарня, уголь, железо, пивоварня по уровням
  (таблица — `engine/src/data/tiles.ts`). 14 жетонов связей.
- Колода по числу игроков: 40 / 54 / 64 карты (локации и отрасли), отдельно 4 «любая локация»
  и 4 «любая отрасль».
- Подготовка: £17 каждому, доход 0 (клетка 10), ПО 0. Колоду перемешать, каждому 1 карту
  в закрытый сброс и 8 в руку. Торговцы: 2 игрока — Shrewsbury, Gloucester, Oxford (5 плиток:
  любой, хлопок, мануфактура, 2 пустых); 3 — + Warrington (+ гончарня, пустая); 4 — + Nottingham
  (+ хлопок, мануфактура). Плитки перемешиваются, у каждой непустой — бочка пива.
  Рынок угля: 13 кубов из 14 мест (£1–£7 по два), железа: 8 из 10 (£1–£5 по два).
  Первый порядок ходов — случайный.

### Ход
- Эпоха каналов, раунд 1: одно действие; все остальные ходы — два действия.
- Каждое действие сбрасывает одну карту (разведка — три). В конце хода добор до 8, пока есть колода.
- Действия:
  - **Строить.** Карта локации — в этом городе (сеть не нужна). Карта отрасли — эта отрасль в
    городе своей сети (если у игрока нет ничего на поле — где угодно). Джокеры: «любая локация» —
    любой город или ферма, «любая отрасль» — любая отрасль в своей сети. Строится самая нижняя
    плитка отрасли с планшета. Уровень 1 (кроме гончарни I) нельзя строить в эпоху ж/д; гончарню V
    и пивоварню IV — только в эпоху ж/д. В эпоху каналов — не больше одной своей плитки в городе.
    Если в городе есть пустой слот только с этой отраслью, строить нужно в него. Перестройка:
    своя плитка той же отрасли с более высоким уровнем; чужая — только уголь/железо, когда
    этого ресурса нет ни на поле, ни на рынке. Снесённая плитка уходит из игры вместе с ресурсами.
    Стоимость: деньги + уголь + железо.
  - **Сеть.** Каналы — 1 связь за £3. Ж/д — 1 связь за £5 + 1 уголь или 2 связи за £15 + 2 угля
    + 1 пиво. Связь должна примыкать к своей сети (или где угодно, если сети нет); вторая —
    к сети с учётом первой.
  - **Развивать.** Убрать с планшета 1 или 2 нижние плитки (за каждую 1 железо). Гончарни I и III
    (лампочка) развивать нельзя.
  - **Продать.** Перевернуть одну или несколько своих хлопковых/мануфактур/гончарен: плитка связана
    с торговцем, принимающим эту отрасль, и тратит указанное на ней пиво. Пиво торговца (бочка у
    подходящей плитки этой точки) даёт бонус точки: Shrewsbury +4 ПО, Nottingham +3 ПО,
    Oxford +2 дохода, Warrington +£5, Gloucester — бесплатное развитие.
  - **Заём.** +£30, доход −3 уровня (не ниже −10).
  - **Разведка.** Сбросить 3 карты, взять «любую локацию» и «любую отрасль»; нельзя, если
    джокер уже на руке. Использованные джокеры возвращаются в запас.
  - **Пропуск.** Сбросить карту.
- Уголь: из ближайшей по числу связей шахты, связанной с местом (любого игрока; при равенстве —
  на выбор), иначе с рынка — если место связано с любой торговой точкой (плитка не обязательна).
  Пустой рынок угля — £8 за куб. Железо: с любого завода без связи, иначе с рынка (пустой — £6).
  Пиво: своя пивоварня где угодно, чужая — связанная с местом, при продаже — бочка торговца.
- Шахта, связанная с торговой точкой, сразу продаёт уголь на рынок (в самые дорогие свободные
  места, деньги игроку); завод всегда продаёт железо. Рынок: N кубов занимают N самых дорогих
  мест; покупка — самый дешёвый куб, продажа — самое дорогое пустое место.
- Пивоварня ставится с 1 бочкой в эпоху каналов, с 2 — в эпоху ж/д.
- Плитка с последним израсходованным ресурсом переворачивается; переворот сдвигает доход
  владельца на значение плитки.
- Все потраченные в ходе деньги (включая покупку на рынке) учитываются для порядка ходов.

### Конец раунда
- Новый порядок: по возрастанию потраченного, при равенстве — прежний порядок.
- Доход по уровню (кроме последнего раунда игры). Отрицательный: платить; не хватает — снимаются
  свои плитки за половину стоимости (сначала неперевёрнутые, дешёвые по ПО), затем −1 ПО за £1.
- Игрок без карт при пустой колоде пропускает оставшиеся действия.

### Конец эпохи (колода и все руки пусты)
- Очки за связи: каждая связь приносит владельцу сумму значков связи на перевёрнутых плитках
  в соседних локациях + 2 за каждую соседнюю торговую точку. Затем ПО перевёрнутых плиток.
- Эпоха каналов → ж/д: убрать все связи и все плитки уровня 1, заполнить бочки торговцев,
  весь сброс перемешать в колоду, раздать по 8. Порядок ходов сохраняется.
- Конец эпохи ж/д — конец игры. Победитель: ПО → уровень дохода → деньги.

## 3. Движок

- Состояние `G`: игроки (имя, цвет, рука, деньги, клетка дохода, ПО, потрачено, взятые с
  планшета плитки по отраслям, жетоны связей, последний сброс), эпоха, раунд, порядок и позиция,
  оставшиеся действия, слоты локаций, построенные связи, торговцы, рынки, колода, сброс,
  джокеры, журнал, итоги эпох, конец игры.
- Действия — ходы boardgame.io с полным описанием (`build`, `network`, `develop`, `sell`, `loan`,
  `scout`, `pass`). Источники ресурсов можно передать явно; без них движок выбирает сам
  (ближайший уголь, первый подходящий завод/пивоварня).
- Модули: `data/*` (таблицы), `graph` (сеть, связность, расстояния), `market`, `resources`
  (план расхода ресурсов), `actions/*` (проверка и применение), `round` (порядок, доход, эпохи),
  `options` (запросы для интерфейса: допустимые слоты, связи, продажи и т.д.), `enumerate`
  (все допустимые действия — для тестов и сетевого скрипта), `view` (скрытие), `game`.
- Скрытое через `playerView`: чужие руки (только число), колода (только число), закрытые
  карты сброса. Перемешивание — `random` boardgame.io, только на сервере.
- Лобби-фаза как в ankh-morpork: имена, цвета (оранжевый, фиолетовый, бирюзовый, жёлтый),
  хост начинает игру.

## 4. Интерфейс

- Стол: поле (SVG поверх скана, зум колесом, перетаскивание) — плитки в слотах (лицо/рубашка),
  связи (баржа/поезд), торговцы и бочки, кубы на рынках, маркеры ПО и дохода, порядок ходов,
  колода. Справа: игроки (деньги, доход, ПО, потрачено, карты, жетоны связей, последний сброс),
  панель действия (мастер) и журнал. Внизу: рука и «Планшет» (следующие плитки по отраслям).
- Мастер: действие → карта → цель на поле → выбор источников (только когда выбор реально есть)
  → итог со стоимостью → «Подтвердить». После всех действий — «Завершить ход»; «Отменить» до него.
- Подсказки на русском: русские названия городов и отраслей во всплывающих подсказках.
- Сигнал «● Ваш ход» в заголовке и звук; подсветка изменений на поле; окно итогов эпохи;
  итоговая таблица. Хотсит: экран передачи хода закрывает руку.

## 5. Проверки

- vitest: подготовка, рынки, связность, каждое действие и его запреты, доход, порядок, смена
  эпохи, финальный подсчёт, сотни случайных полных партий на 2/3/4 игроков с инвариантами.
- `scripts/net-play.mjs`: полная сетевая партия через socket.io-клиентов с проверкой, что
  чужие руки и колода не приходят по сети.
- `scripts/ui-test.mjs` (puppeteer): создание игры, лобби, несколько действий через интерфейс,
  хотсит, скриншоты.
